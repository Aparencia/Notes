# {{date:YYYY-MM-DD}} 日复盘

> [!tip] 三条规则，其余都能空
> 1. 情绪写成「事实 + 分析」，不写自我指责；
> 2. 行动写成「如果…就…」或「打开什么、做多久」，不写「注意点」；
> 3. 每天至少一条具体正反馈；成功经验只记线索，周末再整理。

按时间往下写，只写事实，不归纳不评价。今天推进了什么收在末尾两行。

## 二、学到什么

复盘只记「我学到了什么」。挑一件问 why 和 how，没有就不写，别硬凑。

- 现象（摄像头能拍到的）：
- Why（我原来怎么想 / 现在发现什么）：
- How（下次的具体动作或话术）：
- 值得沉淀：☐ 是 → 场景 / 步骤 1-2-3 / 关键话术 / 例外（周末整理成 SOP）

颗粒度自检：「优化了 / 处理了 / 调整了」后面必须补 对象 + 动作 + 结果，补不上说明还没想清楚。
