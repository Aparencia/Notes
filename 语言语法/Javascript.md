# JavaScript 是什么
是一种运行在客户端（浏览器）的编程语言，实现人机交互效果
作用：
	+ 网页特效
	+ 表单验证(合法性判断)
	+ 数据交换（获取后端数据）
	+ 服务端编程（node.js）
有什么：
	+ ECMAScript
		  基础语法知识
	+ Web APIs
		+ DOM 页面文档对象模型
		+ BOM 浏览器对象模型

# javascript 书写位置
## 内部 js
直接写在 html 文件里，用 script 标签包住。
规范：script 标签写在</body> 上面
将</script>放在 html 文件的底部附近的原因是浏览器会按照代码在文件中的顺序加载 HTML；如果先加载的 JavaScript 期望修改 其下方的 HTML,可能由于 HTML 尚未被加载而失效。
## 外部 js
代码写在以 js 文件内
语法：通过 script 标签，引入到 html 页面中
<script src = 'my.js'></script>
注意此时，script 标签中间写的代码会被忽略
alert('')，页面弹出警告对话框
# 内联 js
代码写在标签内部
语法：vue 框架会用到这种模式
# 注释
## 单行注释
符号： //
作用是：//右边这一行的代码会被忽略
## 块注释
符号：/* \*/ 
作用是在/\*和\*/之间的所有内容都会被忽略
# 结束符
符号：(;)
作用：代表语句结束，js 中的结束符不被强制要求书写，但在实际开发中，要么每句都写，要么每句都不写
# js 的输入输出语法
语法：人与计算机打交道的规则约定
## 输出语法
1.document.write('')
作用：向 body 内输出内容
注意：如果输出的内容写的是标签，也会被解析成网页元素
2.alert('')
作用：页面弹出警告对话框
3.console.log('')
作用：控制台输出语法，程序员调试使用
## 输入语法
1.prompt('')
作用：显示一个对话框，对话框中包含一条文字信息，用来提示用户输入文字
# 代码实行顺序
按 html 文档流顺序执行 js 代码
alert、prompt 会跳过页面渲染先被执行

# 变量
## 变量是什么
白话：变量是一个装东西的盒子
通俗来讲：变量是计算机中用来存储数据的容器，让计算机变得有记忆
注意：变量不是数据本身，它们仅仅是一个用于存储数值的容器。
作用：存储数据
## 变量的基本使用

## 声明变量：
想要使用变量，首先要创建变量（也称为声明变量或定义变量）
语法：`let 变量名`
声明变量有两个部分构成：声明关键字、变量名（标识）
let 即关键字。
## 变量赋值：
定义了一个变量后，就能够初始化它（赋值）。在变量名之后跟上一个“=”，然后数值
注意：通过变量名获取变量值
## 变量初始化：在声明变量的同时完成赋值操作
## 更新变量
变量赋值后，还可以通过简单地给它一个不同值来更新它
注意：let 不允许多次声明一个变量
## 声明多个变量
语法：多个变量中间用逗号隔开。
注意：这种写法不被推荐，为了更好的可读性，应该分别声明。
## 变量的本质
内存：计算机中存储数据的地方，相当于一个空间
变量本质：是程序在内存中申请的一块用来存放数据的空间
变量的命名规则和规范
规则：必须遵守；规范：建议，不遵守不报错但是不符合业内通识
规则：
不能使用关键字
只能用下划线、字母、数字、$组成，不能以数字开头
大小写严格区分
规范：
1、起名有意义
2、遵循小驼峰命名法
第一个单词首字母小写，后面每个单词首字母大写。

# 数组 
数组（array）——一种将数据存储在单个变量名下的优雅方式
声明语法：let 数组名 = \[数据 1，数据 2，···]
数组是按顺序保存的，所以每个数据都有自己的编号
计算机中的编号从 0 开始
在数组中，数据的编号也叫索引或下标
数组可以存储任意类型的数据
取值语法：数组名\[下标]
## 一些术语
元素：数组中保存的每个数据都叫做数组元素
下标：数组中数据的编号
长度：数组中数据的个数，通过数组的 length 属性获得
# 常量的基本使用
概念：使用 const 声明的变量称为“常量”
使用场景：当一个值永远不会改变的时候，就可以用 const 来声明，而不是 let
命名规范：和变量一致
注意：常量不允许被重新赋值，声明的时候必须赋值（初始化）
小技巧：不需要重新赋值的数据使用 const
