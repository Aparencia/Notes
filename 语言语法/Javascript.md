# JavaScript 是什么
是一种运行在客户端（浏览器）的编程语言，实现人机交互效果
作用：
	+ 网页特效
	+ 表单验证(合法性判断)
	+ 数据交换（获取后端数据）
	+ 服务端编程（node.js）
有什么：
	+ ECMAScript
		  基础语法知识
	+ Web APIs
		+ DOM 页面文档对象模型
		+ BOM 浏览器对象模型
